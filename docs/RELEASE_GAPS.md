# Remaining publication gates (after Stage 3E)

1. **Frozen inputs and reproducible entrypoints.** The code-only ZIP contains selected metadata, not FASTQ/counts, mouse/human per-contrast effects, full model outputs, Hallmark ranks/gene sets, or the submitted workbook. Decide which small redistributable datasets can be added and which files need a DOI-hosted analysis-input archive. Provide copy/paste commands with exact input directory conventions for each tested stage.
2. **Large input file.** `00_metadata/analysis_inputs/meta_analysis_v1/HFD_primary105_meta_effects_primaryQC_v1.tsv.gz` is listed at 106,366,306 bytes (approximately 101.44 MiB), exceeding GitHub's usual 100 MiB individual-file threshold. Deposit it in a suitable data archive or supply a rebuild procedure; do not push it as a regular Git blob.
3. **Public data / licensing / privacy.** Review accession mapping, any sample-level phenotype/clinical fields, MSigDB terms of use and reference files. Avoid public credentials, private server paths and undisclosed restricted material. A preliminary text scan is not a substitute for deliberate human review.
4. **Dependency freeze.** Document R/Python package versions, STAR and featureCounts actual binary paths/versions, GRCm39/GENCODE M39 and Ensembl116 provenance, and the MSigDB collection version. Stage 1 found `STAR` and `featureCounts` absent from PATH, not necessarily absent from the host.
5. **Study-selection transparency.** Preserve distinction between historical 671 strict search hits, 107 screened candidate GSEs and final 64 GSEs/105 contrasts. The available GEO discovery code alone cannot reconstruct manual study triage; provide the documented decisions and final selection manifest.
6. **Supplementary tables.** Verify each final S1–S17 value is derived from the existing S1–S22 source tables. The manual selection/renumbering is accurately disclosed; creating a new final-workbook-generation script is not required.
7. **Publication metadata.** Add an appropriate license (after permissions check), authorship/citation information, changelog, release tag, Zenodo deposition and a real DOI; only then update manuscript and reviewer responses. This directory is not yet a published or archived release.

Optional: include figure-rendering scripts for full *figure appearance* reproduction. Their exclusion does not invalidate the tested quantitative analyses, but figures themselves cannot be regenerated from this repository as published.
